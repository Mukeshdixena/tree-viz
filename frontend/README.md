# Grow - All-in-One Learning & Life Tracker

This is a comprehensive dashboard for tracking your personal growth, learning progress, and daily life.

## Features

- **Goals Tracker**: Visualize your big goals broken down into recursive steps (Tree Visualization).
- **Daily Tasks**: A Kanban-style board to manage your daily to-dos.
- **Journal**: A personal diary to record your thoughts and progress.
- **Quick Notes**: Sticky notes for random ideas and reminders.
- **Learning Stats**: Visual analytics of your study time and streak.

## Getting Started

1.  Navigate to `frontend`:
    ```bash
    cd frontend
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```

## Technology Stack

- **React** (Vite)
- **React Router** for navigation
- **Lucide React** for icons
- **Framer Motion** for animations
- **Custom CSS** for styling (Dark Mode supported)
